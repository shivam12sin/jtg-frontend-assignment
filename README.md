# JTG Frontend Home Assignment

A pixel-perfect, fully responsive implementation of the JTG Frontend Assignment Figma mockup.

## 🚀 Overview

This project is built from scratch strictly adhering to the assignment requirements. No external frameworks or libraries (like React, Bootstrap, or jQuery) were used. The layout was carefully structured using modern CSS Flexbox/Grid to match the exact dimensions, colors, and typography of the provided design.

## ✨ Features

- **Pixel-Perfect Design:** Colors, spacing, and typography precisely match the Figma file.
- **Vanilla JavaScript Carousel:** A custom, lightweight carousel built from scratch without jQuery for the Recommendations section.
- **Semantic HTML5:** Extensively uses modern semantic tags (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`) for accessibility and SEO.
- **Fully Responsive:** Layout intelligently adapts to mobile and tablet screens using custom CSS media queries without breaking the design.
- **Zero Dependencies:** Built entirely with raw HTML, CSS, and JavaScript.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3** (Flexbox, Grid, Media Queries)
- **Vanilla JavaScript** (ES6)

## 🏃‍♂️ How to Run Locally

Since this is a static website with no dependencies or build steps, running it is incredibly simple:

1. Clone this repository or download the ZIP.
2. Open the folder in your file explorer.
3. Double-click the `index.html` file to open it in any modern web browser (Chrome, Firefox, Safari).
4. *(Optional)* Use an extension like **Live Server** in VS Code for live reloading.

## 📝 Design Decisions

- **Layout Structure:** `<div>` elements are used exclusively for layout (no tables).
- **Typography:** The **Open Sans** font family is imported from Google Fonts as required.
- **Cross-Browser Compatibility:** Standard CSS properties ensure the site looks identical across all major browsers.
